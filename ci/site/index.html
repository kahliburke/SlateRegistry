Slate Extensions

Extension packages for Kaimon Slate notebooks — @bind controls, output renderers and domain tooling. Browse them here, or inside a notebook with ⌘K → Extensions, which installs them for you.

Adding one by hand, from the Pkg REPL: 
pkg> registry add https://github.com/kahliburke/SlateRegistry
pkg> add <PackageName>
